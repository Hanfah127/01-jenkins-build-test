# 01 — Jenkins Build & Test Pipeline

## Project Overview

My first hands-on CI/CD portfolio project, created from scratch to learn Jenkins pipeline automation, Git version control and GitHub.

## Technologies

- Jenkins
- Jenkinsfile
- Git and GitHub
- PowerShell
- Docker

## Project Files

- `Jenkinsfile` — defines the Jenkins pipeline.
- `app.txt` — initial practice application file.

## Skills Practised

- Creating a Jenkins pipeline.
- Organising work into Build and Test stages.
- Running Linux shell commands.
- Deliberately triggering and investigating a failed stage.
- Using Git to commit and publish project files.

## Pipeline Flow

Build → Test → Result

The pipeline demonstrates how Jenkins executes stages and reports failures.
